# Analysis

This folder contains exploratory analyses and data-validation work for the thesis.

Start with [feature_eda_and_selection.ipynb](exploratory/feature_eda_and_selection.ipynb) for feature coverage and selection, [target_index_eda.ipynb](exploratory/target_index_eda.ipynb) for outcome construction, and [dataset_coverage_verification.ipynb](validation/dataset_coverage_verification.ipynb) for data coverage checks.

The notebooks include exploratory work as well as analyses used to support the thesis. Consult the results summary and model notebooks before treating an exploratory result as a final finding.
