## 🔬 Analysis Pipeline Overview

### Input Data
- **Source:** `../../_tmp_collective_fullsample_export/features/collective_window_features.tsv`
- **Dimensions:** 1521 windows × 44 features (all 10 groups, all tasks)
- **Subset for analysis:** 545 windows (T1–T3 tasks with complete transcripts)

### Processing Steps

1. **Feature Selection & Preprocessing**
   - Select 10 diagnostic features
   - Handle missing values (mean imputation)
   - Z-score normalization within groups
   - Result: Clean 545×10 feature matrix

2. **Dimensionality Reduction**
   - PCA: 10 → 7 dimensions
   - Variance retained: ~80%
   - Used for HMM observation model

3. **HMM Fitting & Selection**
   - Model: Gaussian HMM with Baum-Welch EM algorithm
   - BIC selection: k = 2–6 states tested
   - **Selected:** k = 5 states (BIC = 11019.6, lowest score)
   - Convergence: 15–20 iterations

4. **State Inference**
   - Viterbi decoding: MAP state sequence
   - Output: `../results/hmm_cluster_assignments_k5_updated_overlaps.tsv`
